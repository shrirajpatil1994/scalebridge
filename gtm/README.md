# Go-to-market (draft)

1. **Pilot: Mumbai.** BMC and related departments, alongside the Urban Development Department's study group on AI/GIS audit of civic works (GR, 29 Jul 2026). Twelve weeks, one module, shadow mode, read-only access, metrics agreed up front.
2. **Buyers:** Municipal Commissioner (owner), UDD Principal Secretary, MahaIT (technology), Chief Auditor / vigilance. For M4: CAG IT / CDMA, legislature committees (PAC), civil society and media (public-data version).
3. **Route:** MoU or innovation-challenge pilot → GeM / tender for scale-up. Parallel track: the CAG's May 2026 expression of interest for a Sovereign AI Platform.
4. **Pricing logic:** fixed-fee pilot → per-module subscription per body → state platform licence.
5. **Land → expand:** BMC → UDD (all municipal corporations and councils) → MHADA / SRA / CIDCO / MMRDA → other states → Gulf municipalities and audit institutions.
6. **Risks:** procurement cycles; data access; political sensitivity of "leakage" findings (mitigation: patterns, not accusations, with citations); the CAG's in-house build (mitigation: complement it, auditee-side first).
